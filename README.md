# Agendamento de Serviços

**Agendamento de Serviços** (Entidades: *Clientes* e *Agendamentos*)

### 🛠️ O QUE O PROJETO DEVE CONTER?

1. **API RESTful (Express):** CRUD completo para 2 entidades, tratamento correto dos códigos HTTP (200, 201, 400, 404), validação de payload e suporte a Query Params.
2. **Script Bash Automatizado (`testes.sh`):** Teste de todas as rotas usando `curl` e `jq`, gerando relatório em `resultado_execucao.log`.
3. **Ambiente Debian Linux:** Gerenciamento de processos (`ps aux`, `kill`) e `package.json` bem estruturado.
4. **Git & GitHub:** Commits equilibrados de **ambos os alunos** e `README.md` completo documentando a API.
